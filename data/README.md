# Input data (not included)

Place the raw HRS files in `data/original data/` (RAND HRS longitudinal file, HRS core interview files and the HRS 2022 Tracker `trk2022tr_r.dta`; available to registered researchers at https://hrs.isr.umich.edu). The preprocessing notebooks write the wave-level tables to `data/preprocessed data/`. Both folders contain HRS-derived participant-level data and are ignored by Git.
