# Calculation outputs

Everything under this folder except this file is generated by `run_benchmark.py` and `run_table_sources.py` and is ignored by Git (it contains participant-level outputs). Layout: `cohorts/`, `imputation/`, `checkpoints/`, `predictions/`, `importance/`, `imputation_comparison/`, `tables/` (with `tables/supplementary/` for Table 1 and Supplementary Tables S1–S26) and `logs/`. See `REPRODUCIBILITY.md`. The saved aggregate tables are in `delivery/tables/audited_sources/`.
